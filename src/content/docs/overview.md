# 文档总览

Pudding 是一个运行在 Windows 上的本地工具助手：你在对话里提出需求，它查询和修改工具软件的配置、组织要执行的操作，再交给对应的软件完成。数据保存在本机，模型由你自己配置。

## 当前支持的工具

| 工具软件 | 状态 |
| --- | --- |
| BetterGI（原神） | 已适配 |
| 三月七小助手（崩坏：星穹铁道） | 内置接入插件，默认停用 |
| ZZZ一条龙（绝区零） | 内置接入插件，默认停用 |
| MaaEnd（明日方舟：终末地） | 内置接入插件，默认停用 |

BetterGI 可以直接连接使用；另外三个工具需要在软件里启用对应的插件，并手动启动、连接相应工具后才能使用。详见[连接工具](connections.md)。

## 快速开始

1. 安装软件并配置一个模型，见[安装与配置](guide.md)。
2. 连接你想使用的工具，见[连接工具](connections.md)。
3. 在对话里发起第一个请求，见[对话与审批](chat.md)。
