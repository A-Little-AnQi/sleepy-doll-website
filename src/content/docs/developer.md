# 开发者的话

## 先发出来，给大家试试看

这个软件还没做好。我想先发一个测试版，让大家感受一下用对话操作游戏助手是什么样，也看看实际使用时还缺什么。

现在发布的是 **0.0.1**，目前接入了 BetterGI。界面、操作流程和说明还有要改的地方，遇到问题欢迎直接提。

如果它没有理解你的要求，或者执行到一半卡住了，把你当时怎么说的、它怎么回答的、哪里出了问题告诉我，比一句「不好用」更容易定位。

## 接下来准备做什么

先把已经有的东西做稳：

- 把 BetterGI 的配置、任务和停止流程继续核对一遍。
- 改善对话和补充信息的交互，减少反复解释。
- 把常用操作整理成更方便复用的快捷任务。
- 补齐使用说明，处理大家试用时遇到的问题。

正式版本计划叫 **0.1.0**。等这些基本流程更稳定了，再考虑接入其他工具。暂时不排一个很满的时间表，做完什么就更新什么。
