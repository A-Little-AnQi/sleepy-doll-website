# 项目与反馈

## 项目方向

Pudding 是面向工具软件的通用本地助手：先在 BetterGI 上做深，同时以桥接插件的方式接入更多工具，让查询配置、组织操作和自动化执行都通过对话完成。快捷任务与定时任务会随实际使用反馈继续打磨。

## 源码

软件源码以 GPL-3.0-only 发布：

- [Pudding 主程序与桥](https://github.com/Pudding-Player/Pudding)
- [本站源码](https://github.com/A-Little-AnQi/sleepy-doll-website)
