# 开发者的话

## 关于 0.1.0

0.1.0 正在准备发布。这个阶段先把已有功能交给大家实际使用，再根据反馈继续完善。

后续开发按以下顺序推进：

1. 完善 BetterGI 的全部功能适配。
2. 建立原神知识体系。
3. 优化语音输入和图片输入。
4. 完善快捷指令。
