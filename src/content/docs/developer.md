# 开发者的话

## 关于 0.1.0

0.1.0 先把已有功能交给大家体验。软件还在完善中，后续会根据实际使用反馈继续改进。

## 后续计划

后续开发按以下顺序推进：

1. 完善 BetterGI 的全部功能适配。
2. 完善原神知识体系。
3. 补充语音输入和图片输入。
4. 完善快捷指令。
5. 添加定时任务辅助

## 源码

0.1.0 的软件源码暂不开放。正式版发布时，一次性开源完整源码。
