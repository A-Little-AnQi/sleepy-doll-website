# 对话与审批

在对话里描述需求，Pudding 会查询信息、准备操作，并按你设置的审批级别执行。

## 发起查询

新建对话后，在输入框右下角选择模型，然后直接输入需求。例如选择「只读」后先尝试查询：

> 列出所有调度器配置组。

提出操作需求时，请写明目标（如配置组或脚本名称）和要完成的修改，描述越具体，结果越可靠。

## 操作审批

审批级别决定 Pudding 执行操作前是否需要你确认：

| 审批级别 | 行为 |
| --- | --- |
| 只读 | 只查询信息，不修改配置、不启动任务 |
| 请求审批 | 修改配置或执行任务前，先展示内容并等待确认 |
| 完全控制 | 按需求直接执行，不再逐次确认 |

默认使用「请求审批」。执行过程中需要补充信息时，会在问题卡片中列出选项，选择或填写后提交即可继续。

## 执行记录与停止

点击回复旁的「用时」可以查看每次工具调用的参数和返回结果，便于核对实际做了什么。

停止操作分几种情况：

- 当前对话的任务可用输入框右侧的停止按钮结束。
- 全部任务可按 **Ctrl+Alt+Q** 或使用托盘菜单停止。
- 已经交给 BetterGI 等工具执行的动作，需要在对应工具中停止。

停止对话不会撤销已经完成的修改；如需回退，请在对话里明确说明要改回的内容，或在对应工具中处理。

## 运行记录入口

不同功能的运行记录入口不同：

- 普通对话的执行情况在对话内查看。
- 快捷任务的运行情况在「快捷任务」页的「运行记录」中查看。
- 定时任务的每次触发结果在该任务的「运行记录」中查看。

相关内容见[快捷任务](quick-tasks.md)和[定时任务](scheduled-tasks.md)。
