# 使用说明

Sleepy Doll（发条枢）给游戏助手接入 AI。目前支持 BetterGI，模型需要自己配置。

## 快速上手

### 第 1 步 添加模型

在「本地用户 → 设置 → 模型」中添加模型，填写协议、API 地址、Key 和模型标识。回到新对话，在输入框右下角选中它。

### 第 2 步 连接 BetterGI

打开 BetterGI，在 Sleepy Doll 的侧栏点击「BetterGI → 连接」。侧栏没有入口时，先到「工具与扩展 → 插件」启用 BetterGI。

### 第 3 步 试一次查询

把审批级别切到「只读」，发送：

> 列出我现有的调度器配置组。

查询成功后，再试修改配置或运行任务。提要求时带上配置组、脚本等对象的名称。

## 审批级别

| 级别 | 权限 |
| --- | --- |
| 只读 | 查询，不修改或运行任务 |
| 请求审批 | 修改和执行前确认 |
| 完全控制 | 直接执行 |

默认使用「请求审批」。需要补充信息时，在问题卡片里填写并提交。

## 进度和停止

点击回复旁的「用时」查看工具调用。停止当前任务用输入框右侧按钮；停止全部任务用 **Ctrl+Alt+Q** 或托盘菜单。

如果 BetterGI 仍在执行，也到 BetterGI 中停止。已完成的修改不会撤销。

## 快捷任务

完成后点击「保存为快捷任务」，取一个名称，下次在「快捷任务」页运行。纯问答、未完成或缺参数的操作可能没有保存入口。

## 技能和插件

技能提供操作说明，插件接入工具。在「工具与扩展」中安装和启用；插件附带的技能随插件开关。

## 更新和备份

在设置中检查更新，可切换正式与测试通道。原目录更新保留设置和对话。

备份时先退出程序，再复制程序目录里的 `user` 文件夹。

## 数据和费用

对话及工具结果会发送到你配置的模型 API，费用以服务商账单为准。Key 以明文保存在本机 `config.json`，分享配置或日志前请去掉密钥。

匿名统计默认关闭，可在设置中开启或关闭。
