# 使用说明

Sleepy Doll（发条枢）是给游戏助手用的 AI 工具，主要面向普通用户。目前支持 BetterGI。

## 快速上手

先以 BetterGI 为例，把模型和工具连好。

### 第 1 步 添加模型

1. 点左下角「本地用户」→「设置」→「模型」。
2. 点击「添加模型」，选择服务商，填写名称、请求协议、API 地址和 API Key。具体填法可以参照服务商的 API 文档。
3. 选择要用的模型，保存。回到「新建对话」，在输入框右下角选中它。

不确定通没通？先发一条不用工具的消息：

> 不调用工具，请只回复「连接正常」。

收到回复，就说明模型已经连好了。之后能把事情做到什么程度，还要看你选的模型。

### 第 2 步 连接 BetterGI

1. 先打开 BetterGI。
2. 点击侧栏的「BetterGI」，或者进入「设置」→「BetterGI」。
3. 点击「连接」，等待显示「已连接」。

侧栏里没有 BetterGI？到「工具与扩展」→「插件」，把 BetterGI 插件打开。

### 第 3 步 试一次查询

先把输入框左侧的审批级别切到「只读」，再发一句：

> 列出我现有的调度器配置组，不运行任务，也不修改配置。

能返回配置组名称，就可以继续试着改参数或整理任务了。没有配置组时，返回空列表也正常。

说要求时，把对象和目标说清楚。例如：

> 把「日常采集」配置组里的运行顺序调整一下，先执行我刚添加的脚本。

需要补充信息时，在问题卡片里选择或填写答案，再提交。

## 怎么提要求

可以直接说你要查什么、改什么。涉及已有配置时，尽量带上完整名称。

- 查找脚本：告诉它脚本名称，或者你想完成的事情。
- 修改配置：说明改哪个配置组、哪个参数，以及希望改成什么。
- 整理任务：说明要用哪些脚本、执行顺序和结束条件。
- 看运行结果：指出是哪一次任务，或者让它查看最近的记录。

不用一次把所有信息写完。运行中也可以继续补充要求。

## 审批级别

| 级别 | 会发生什么 |
| --- | --- |
| 只读 | 查询信息，不修改配置，也不启动任务 |
| 请求审批 | 修改或执行前，先让你确认 |
| 完全控制 | 按你的要求执行，省去逐次确认 |

日常使用可以保留默认的「请求审批」。确认卡片会列出对象和参数，看过之后再选允许或拒绝。

## 查看进度和停止任务

回复旁的「用时」可以展开，查看调用过哪些工具、返回了什么结果。输入框右下角的圆环显示模型上下文占用，不是账户余额。

停止当前任务，点输入框右侧的停止按钮。停止所有任务，可以按 **Ctrl+Alt+Q**，或使用托盘菜单。

点击后可能会先显示「正在停止」。如果接入的工具还在运行，也可以到 BetterGI 中停止。已经完成的配置修改不会被撤销。

## 保存快捷任务

常用的操作可以保存为快捷任务，下次直接运行。

完成后出现「保存为快捷任务」入口时，点击并设置名称。纯问答、未完成的操作，或还缺参数的任务，可能没有这个入口。

在「快捷任务」页可以运行、改名和查看记录。想调整内容，可以在对话里提出新的要求。

## 技能和插件

技能是给模型看的操作说明。插件负责接入工具，也可以附带技能。

在「工具与扩展」中安装和启用。插件附带的技能会跟着插件开关；自己导入的技能可以单独管理。只安装你信任的来源。

## 更新和备份

新版本可以在「设置」中检查。现在发布的是测试版；正式版与测试版可以分别选择。

使用安装包在原目录更新，会保留设置和对话。便携目录没有安装登记时，下载安装包后按界面操作即可。

需要备份或迁移时，先退出程序，再复制程序目录里的 `user` 文件夹。实际配置路径也会显示在设置页。

## 数据和模型费用

模型服务和 API Key 由你自己配置，调用费用以服务商的账单为准。对话和相关工具结果会发送到你填写的 API 地址。

在界面中填写的 Key 会以明文保存在本机 `config.json` 中。分享配置、截图或日志前，先去掉 Key 和 token。

匿名基础统计默认关闭，可以在设置里开启或关闭。它记录启动、检查更新和更新结果，不记录对话内容。

## 遇到问题

先看[常见问题](faq.md)。仍然解决不了，可以到 [GitHub 提交 Issue](https://github.com/A-Little-AnQi/Sleepy-Doll/issues)，写清版本、操作步骤、期望结果和实际结果。报错截图或对应时间的日志也有帮助，不需要上传整个数据目录。
