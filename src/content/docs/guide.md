# 安装与配置

从安装 Pudding 到完成模型设置，之后就可以连接工具并开始对话。

## 安装

从[官网](https://sleepy-doll.restless-nh3.com)下载 Windows 安装包并安装。Pudding 是本地软件，设置与对话保存在安装目录的 `user` 文件夹中。

## 配置模型

对话功能需要一个模型。点击左下角头像，进入「设置 → 模型」，点击添加并填写：

| 字段 | 说明 |
| --- | --- |
| 协议 | 模型服务的接口协议：OpenAI Responses、OpenAI 兼容（Chat Completions）、Anthropic、Google Gemini 或 Ollama |
| API 地址 | 服务商提供的接口地址 |
| API Key | 你在服务商处创建的密钥，用于调用鉴权 |
| 模型标识 | 要使用的模型名称，需与服务商文档中的精确名称一致 |

各字段的具体取值以所选服务商的官方文档为准。使用 Ollama 本地模型时不产生模型调用费用。

保存后，在新对话输入框右下角选择该模型即可开始使用。

## 连接工具

模型配置完成后，连接要使用的工具软件。BetterGI 已适配，可直接连接；三月七小助手、ZZZ一条龙与 MaaEnd 需要先启用对应插件。具体步骤见[连接工具](connections.md)。

连接后就可以在对话里发起请求，操作方式与注意事项见[对话与审批](chat.md)。

## 检查更新

在「设置 → 关于」中检查更新并安装新版本。在原安装目录上更新会保留设置与对话。

## 备份与恢复

备份或恢复前请先退出程序，再复制安装目录中的 `user` 文件夹。恢复时把它放回安装目录即可。模型等配置保存在 `user/config.json`。

如果不再使用 Pudding，注意卸载会一并删除本机保存的设置与对话（`user` 文件夹）：有需要保留的内容，请在卸载前先备份。

## 隐私与费用

调用模型时，对话内容和相关工具结果会发送到你配置的 API 地址，费用以模型服务商的账单为准。API Key 明文保存在本机 `user/config.json` 中，分享配置或日志前请先移除密钥。使用统计可在设置中开启或关闭。

遇到问题可先查阅[故障排查](faq.md)。
