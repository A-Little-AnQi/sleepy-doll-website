# 使用指南

完成模型配置并连接 BetterGI，即可通过对话管理配置、脚本与任务。

## 快速开始

### 第 1 步 配置模型

点击左下角「本地用户」，进入「设置 → 模型」。添加模型并填写协议、API 地址、API Key 和模型标识，在新对话的输入框右下角选择该模型。

### 第 2 步 连接 BetterGI

启动 BetterGI，在侧栏进入「BetterGI」并点击「连接」。未显示该入口时，先在「工具与扩展 → 插件」启用 BetterGI。

### 第 3 步 发起查询

选择「只读」审批级别，尝试查询已有配置：

> 列出所有调度器配置组。

提出操作需求时，请明确配置组或脚本名称，以及需要完成的修改。

## 操作审批

| 审批级别 | 操作范围 |
| --- | --- |
| 只读 | 查询信息，不修改配置或启动任务 |
| 请求审批 | 修改配置或执行任务前，等待确认 |
| 完全控制 | 按需求直接执行，无需逐次确认 |

默认采用「请求审批」。需要补充信息时，在问题卡片中选择或填写答案后提交。

## 执行记录与停止

点击回复旁的「用时」查看工具调用与返回结果。当前任务可通过输入框右侧按钮停止；全部任务可使用 **Ctrl+Alt+Q** 或托盘菜单停止。

停止不会撤销已完成的修改。BetterGI 仍在运行时，请在 BetterGI 中停止对应任务。

## 快捷任务

通过「保存为快捷任务」保存已完成的操作，并在「快捷任务」页重复运行。纯问答、未完成或参数不完整的操作可能不提供保存入口。

## 技能与插件

在「工具与扩展」中安装和启用插件、导入技能。插件提供工具接入，技能提供操作说明；插件附带的技能随插件启用或关闭。

## 更新与备份

在设置中检查更新，并选择正式或测试通道。原安装目录更新会保留设置与对话。

备份前请退出程序，再复制程序目录中的 `user` 文件夹。

## 隐私与费用

模型请求包含对话和相关工具结果，发送至你配置的 API 地址，费用以模型服务商账单为准。API Key 明文保存在本机 `config.json` 中，分享配置或日志前请移除密钥。

使用统计默认关闭，可在设置中开启或关闭。
