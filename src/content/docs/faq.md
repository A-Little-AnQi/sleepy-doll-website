# 故障排查

## 定时任务未触发

1. 确认这条任务的卡片开关处于打开状态。
2. 有错误提示时，从卡片的更多菜单打开「查看问题」，按显示的原因处理。
3. 打开该任务的「运行记录」，先查看这一轮的运行状态：
   - 没有对应记录时，先核对执行时间、本机时区与[触发条件](scheduled-tasks.md#触发条件)；关机或休眠期间错过的触发不会补跑。
   - 状态为失败或部分完成：按这轮记录的错误信息处理。
   - 结果未确认：先核对对应工具的状态，再决定是否重新运行。

## 任务库中没有目标任务

1. 确认目标操作已经保存为快捷任务。
2. 在任务库的「快捷任务」分组里找：用列表顶部的搜索按标题或内容查找，搜索词不适用时先清空，避免目标被过滤掉。
3. 确认对应工具已连接，且该内容支持定时执行。
4. 快捷任务入口修改或删除后，移除失效执行项，重新选择当前有效任务再保存。
