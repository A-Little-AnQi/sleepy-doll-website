# 常见问题

## 模型无法回复时如何排查？

核对协议、API 地址、API Key 和模型标识，并检查模型账户余额与调用权限。修正后可直接重试。

## 旧对话如何切换模型？

在输入框右下角重新选择模型。默认模型仅用于新对话，正在执行的任务继续使用启动时的模型。

## BetterGI 无法连接怎么办？

确认 BetterGI 已启动，并允许 Sleepy Doll 使用管理员权限。同时运行多个 BetterGI 时，仅保留需要连接的程序。

## 任务为什么处于等待状态？

等待状态通常表示需要审批或补充信息。返回原对话，处理对应卡片后继续。

## 哪些操作可以保存为快捷任务？

已完成、参数完整且可重复执行的操作可以保存。纯问答和未完成任务不支持直接保存。

## 停止后为什么仍在运行？

部分任务由 BetterGI 执行，请检查其运行状态，并在 BetterGI 中停止仍在执行的任务。停止不会撤销已完成的修改。

## 输入框圆环表示什么？

圆环显示当前对话的上下文用量，悬停可查看详情。模型调用费用请以服务商账单为准。

## 关闭窗口后如何退出？

启用托盘时，关闭窗口会将程序收起到托盘。右键托盘图标选择「退出」，或在设置中关闭托盘功能。

## 更新和卸载会删除数据吗？

原目录更新会保留用户数据。卸载默认保留数据，仅在选择删除用户数据时移除。备份前请退出程序，再复制 `user` 文件夹。

## API Key 和对话存在哪里？

API Key 明文保存在本机 `config.json` 中，对话保存在本机。模型请求会将对话和相关工具结果发送至配置的 API 地址。请勿公开包含密钥的配置或日志。
