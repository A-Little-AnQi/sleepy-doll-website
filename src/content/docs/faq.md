# 常见问题

## 模型不回复，先查哪里？

先检查 API Key、请求协议、API 地址和模型标识。模型账户的余额和调用权限，到服务商的平台查看。

修改后直接重试，不用重启程序。可以先发送「不调用工具，只回复连接正常」，确认模型能够回复。

## 默认模型改了，旧对话为什么没跟着变？

默认模型用于新对话。旧对话要在输入框右下角重新选择；正在执行的任务仍使用开始时的模型。

## BetterGI 一直连不上怎么办？

先确认 BetterGI 已打开，并允许 Sleepy Doll 使用管理员权限。点击连接后，按具体报错处理。

如果开了多个 BetterGI，只保留要连接的那个。侧栏没有 BetterGI 入口时，到「工具与扩展」中启用对应插件。

## 任务在等我确认或补充信息，该怎么操作？

回到提出要求的对话。确认操作时，检查卡片里的对象和参数，再选允许或拒绝。

需要补充信息时，在问题卡片里选择或填写答案，然后提交。切到其他页面不会取消这次等待。

## 为什么有些操作不能保存成快捷任务？

保存需要一份可重复执行的任务。纯问答、还没完成的操作，或缺少必要参数的任务，可能没有保存入口。

如果确实是常用操作，可以直接告诉它：把这项操作整理成下次可以运行的快捷任务。

## 点了停止，游戏为什么还在动？

先等「正在停止」结束。如果 BetterGI 仍在执行，到 BetterGI 中也点停止。

停止不会撤销已经完成的操作。**Ctrl+Alt+Q** 不起作用时，使用对话里的停止按钮或托盘菜单。

## 右下角的圆环是余额吗？

不是，是这段对话占用的模型上下文。悬停可以看具体用量，费用要看模型服务商的账单。

## 关掉窗口，是退出程序吗？

托盘开启时，关闭窗口会收起到托盘。要退出，右键托盘图标选择退出。

在设置里关闭托盘后，关闭窗口就会退出程序。

## 更新会丢设置和对话吗？

在原安装目录更新会保留用户数据。想多留一份备份，先退出程序，再复制 `user` 文件夹。

卸载默认也保留用户数据，只有你勾选删除时才会移除。

## 我的 Key 和对话会发到哪里？

Key 用来调用你配置的模型 API，对话和相关工具结果也会发送到该地址。程序不会替你选择模型服务商。

Key 在本机配置文件中以明文保存。不要公开完整的 `config.json`，发截图或日志前先检查一遍。

## 怎么反馈问题？

到 [GitHub Issues](https://github.com/A-Little-AnQi/Sleepy-Doll/issues) 提交，带上 Sleepy Doll 和 BetterGI 的版本、操作步骤、报错，以及你原本希望得到的结果。

不用发整个数据文件夹，也不要发模型密钥。
