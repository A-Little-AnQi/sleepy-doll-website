# 更新日志

## 近期功能更新

以下功能已在新版本中提供，具体版本号以安装包为准。

- 快捷任务封装：可在对话中直接创建，也可用封装表单描述已有任务，经只读定位和入口预览后保存。
- 快捷任务组合：支持按顺序组合多个已有动作，并在步骤之间加入固定等待。
- 定时任务：支持指定日期、按天、每周、每月四类时间规则，按顺序执行最多 32 项快捷任务，并提供任务库、默认收尾项、运行记录与停止。
- 更多工具接入：三月七小助手、ZZZ一条龙与 MaaEnd 的桥接随安装包提供，默认停用，可按需启用。
- 定时执行到点不调用模型，运行记录区分已完成、部分完成、失败、结果未确认等状态。
