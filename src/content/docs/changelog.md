# 0.0.1 · 测试版

这是先发出来试用的版本，正式版还在准备。

## 这版包含什么

- 添加自己的模型，连接 BetterGI，用对话查询和修改配置。
- 查找脚本、整理调度组、运行任务并查看记录。
- 保存可重复执行的快捷任务。
- 操作审批、补充信息、停止按钮和托盘菜单。
- 检查更新、下载校验，以及在原安装位置更新。
- 可以自行开启或关闭的匿名基础统计。

## 下一版

正式版本计划使用 **0.1.0**。先把现有流程和已发现的问题处理好，再考虑增加新的接入。

具体更新会继续写在这里，也可以查看 [GitHub 发布记录](https://github.com/A-Little-AnQi/Sleepy-Doll/releases)。
