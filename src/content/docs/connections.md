# 连接工具

Pudding 本身不包含这些工具软件：每个工具都需要单独安装，再在 Pudding 中连接后使用。

当前可连接的工具：

| 工具软件 | 游戏 | 状态 |
| --- | --- | --- |
| [BetterGI](https://github.com/babalae/better-genshin-impact) | 原神 | 已适配 |
| [三月七小助手](https://github.com/moesnow/March7thAssistant) | 崩坏：星穹铁道 | 内置接入插件，默认停用 |
| [ZZZ一条龙](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon) | 绝区零 | 内置接入插件，默认停用 |
| [MaaEnd](https://github.com/MaaEnd/MaaEnd) | 明日方舟：终末地 | 内置接入插件，默认停用 |

## 连接 BetterGI

1. 启动 BetterGI。
2. 在 Pudding 侧栏打开「BetterGI」页，点击「连接」。
3. 连接成功后，可在该页查看当前可用的接口。

如果 BetterGI 没有提前打开，按页面提示先启动它再连接；也可以在连接页把自启动设为打开 Pudding 时自动启动 BetterGI。

## 连接三月七小助手、ZZZ一条龙或 MaaEnd

这三款工具的接入插件内置于 Pudding 安装包中，默认停用，工具本体仍需单独安装：

1. 在「工具与扩展 → 插件」中启用对应的插件。
2. 手动启动对应的工具软件。
3. 在侧栏打开该工具的页面并点击连接。

各工具当前支持的操作范围以连接页展示的内容为准。插件保持停用时不会启动这些第三方软件。

## 技能与插件

「工具与扩展」页分为技能和插件两类：

- 插件提供工具接入，启用后 Pudding 才能连接并操作对应软件。
- 技能提供操作说明，帮助模型了解特定任务的完成方式。

可以在该页导入本机的技能或插件。插件附带的技能会随插件一起启用或停用。
